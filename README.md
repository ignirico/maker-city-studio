# A Maker City · 导演参考画板

muShenzhen 2026 的 8 分钟纪录片脚本与共享视觉参考工作台。内容来自用户提供的《muShenzhen 2026 - 脚本 (1).docx》，保留全部脚本正文；页面标题与空白画板提示属于网站文案。

## 浏览与编辑

甲方直接打开网站，按七个章节阅读脚本及对应参考，也可以浏览「整体视觉」。网站不要求访客登录；任何获得链接的人都可以查看内容，noindex 只用于减少搜索引擎索引，不构成访问控制。

创作团队点击「导演工作室」，输入单独交付的编辑口令。王晴萱导演可以批量上传图片、影片与音频，粘贴影片链接，或添加便签。拖动卡片顶部移动，拖右下角缩放，使用「叠」置于前方；也可用键盘方向键移动或缩放。双击便签编辑。点击「发布更新」共享当前编排。未发布的编辑保留于当前页面，离开前有提示；上传的文件已在服务器保存。

桌面端自由排版；手机按卡片顺序排列，编辑时可以上下调序。单个文件上限 90 MB，推荐 MP4 / H.264、WebM、JPG、PNG 或 WebP；MOV 的浏览器兼容性取决于编码。更大影片使用链接。YouTube、Vimeo、Bilibili 常见链接可内嵌，受来源站点限制时可打开原片；中国大陆访问海外平台的效果取决于网络。

## 架构与部署

- GitHub Pages 从 `main` 的 `/docs` 发布前端。`public/` 为源文件，构建时同步到 `docs/`。
- Sites Worker 部署相同界面与共享 API。R2 的 `state/board.json` 存画板，`media/` 存素材。数据跨设备持久保存。
- 编辑口令只存在托管环境变量 `EDITOR_KEY`，不在仓库或前端；浏览器仅在当前标签页会话中保存用户输入。
- 共享写入使用 R2 ETag 条件更新，阻止旧版本覆盖。遇到冲突会保留当前页面并导出未发布 JSON 备份；备份可供手动合并，暂未提供自动导入界面。
- 从画板移除卡片并发布后，该引用被移除；上传文件保留在存储中以便恢复和避免误删，需要后续维护时再清理。
- 此网站不提供逐人身份验证，持有编辑口令即拥有编辑权限。口令如需轮换，更新 Sites 环境变量后重新部署。

```sh
npm test
npm run build
npm run dev
```

本地预览使用内存存储，口令为 `local-preview-only`，重启即清空；与线上数据独立。生产口令不得写入文件。`npm run build` 将前端嵌入 `dist/server/index.js` 并生成 GitHub Pages 的 `docs/`。

Sites 部署按插件的 source workflow 上传源代码与构建包，再保存并发布版本。GitHub Pages 的后续页面变更需要构建、提交并推送 `main`。前端部署与 API 部署使用同一份源代码。
